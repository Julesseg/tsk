# Edit tasks in the current list

Task editing and capture use an expanding task row in the current list, replacing the separate task-detail page and native editor sheet, to preserve the user's place while acting on work. Existing visible elements move to their expanded positions, additional controls fade in, and the container resizes while surrounding rows move aside and dim; capture inserts a new row already expanded, and tapping outside saves valid changes and collapses the editor, with no Cancel button. This deliberately takes on custom layout, focus and gesture coordination in exchange for continuity between scanning and editing; rows remain anchored until editing finishes, and existing task links reveal a containing list and expand the task, preserving a route back. Detailed behavior is recorded in the [design audit](../design-audit.md).
