# One-time Reminders copy

The workspace offers Copy from Reminders in the compact More menu and iPad sidebar. The native sheet requests full Reminders access, lists source lists, defaults each selected list's destination project to its list name, and permits a different project or no project. Preview shows eligible content, planned date, deadline, priority and skipped-item reasons. Copy refetches selected incomplete reminders before creating durable tasks. Results distinguish copied, skipped and failed items. Ordinary task management remains available after optional Reminders permission or fetch failures.

Core owns mapping and orchestration through TaskManager.previewReminderImport and copyReminders. ReminderSource supplies value snapshots without individual source IDs. There is no source-derived task UUID, per-item provenance, processed-ID set, persisted result, import history, or import metadata file. Repeating a copy intentionally creates independent new tasks; the sheet explains this. Each task uses common create, the semantic mutation lease, durable native commit and local synchronization hook. A failed task save is reported without acknowledging a successful copy.

Supported fields are title, verbatim notes and URL as separate timestamped annotations, startDateComponents as scheduled/planned date, dueDateComponents as deadline, and priority. All incomplete priorities are fetched: Apple 0 maps to no priority, 1–4 to H, 5 to M and 6–9 to L. The source component calendar and timezone take precedence; missing timezone uses its calendar's timezone or the current device calendar. Date-only values resolve to midnight in that calendar and timezone at copy time. Invalid or incomplete dates are skipped with a reason, rather than losing their supplied date fields. Core tests include a 23-hour daylight-saving boundary. Attachments and unverified recurrence conversion are outside this slice. A reminder with recurrence rules is left untouched with an explanation; this is a temporary boundary before #34, not a claim that rejecting every rule completes recurrence import.

The production EventKit adapter only requests access, enumerates lists and reads incomplete reminders. It contains no save/remove reminder call. Authorization is checked for each read and again after fetch. Missing selected lists, revoked permissions and nil fetch results produce genuine errors. Source objects and reminder identifiers are not retained in the import model.

## Real platform gate

Canonical CI creates an owned disposable simulator for each iPhone/iPad lane, boots it through the common cleanup wrapper, and deletes only that simulator afterwards. Existing simulators are untouched. The Reminders XCUITest resets actual app authorization, exercises real denial and subsequent ordinary capture, then separately grants actual permission and creates UUID-named local fixture lists. Fixture writes are compiled only for DEBUG simulator builds and require an explicit isolated-run environment flag. No personal source is used as a fallback. A missing local source is a failing platform prerequisite with source-availability diagnostics, not a passing fake or skipped test.

The real fixture seeds selected incomplete high/no-priority reminders, completed and unselected exclusions, and a recurring source. The user flow previews and copies through the production adapter and Core, reopens durable app-visible tasks, and compares complete selected-source snapshots before and after copying. A separate owned weekly UTC series records every stored recurrence selector, calendar, timezone, first incomplete anchor, five completions, complete records before/after source removal and remaining incomplete records. This evidence is intended for the later #34 mapping decision; frequency labels alone do not establish conversion support. Only the owned fixture lists are cleaned.

Native fixture JSON is collected before simulator shutdown into .build/eventkit-fixture. The successful UI scenario also attaches the report and screenshots to XCResult. Failure JSON is retained for diagnosing source availability, normalized stored selectors, sequence timing or removal behavior. The existing pinned real sync server, independent peer, signing and intent-artifact checks remain in the lane.

## Verification boundary

Public Core mapping and failure tests pass, as does the actual native persistence/reopen/Taskwarrior export check. Signed generic App/XCUITest compilation proves the EventKit adapter, simulator-only fixture and test source compile together. No local simulator was booted and no host personal account was accessed. Real EventKit runtime, stored rules, sequence/removal observations, permission prompts and screenshots remain pending the canonical iPhone/iPad run. Neither compilation nor the Core reminder source test double establishes those platform facts. iCloud/Exchange account behavior, physical keyboard/device use and background execution are unverified.
