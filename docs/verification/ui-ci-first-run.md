# UI automation failures on the first planning CI run

The iPhone SE (3rd generation), iOS 26.2 simulator run for commit `e2a77f5` failed two tests. Core, Native, and archive checks passed. These findings come from the actual XCUITest result bundle and its screenshots, synthesized touch events, and screen recordings.

The planning test saved an undated task. Its screenshot immediately before Save shows both Planned day and Deadline switches off. Recorded switch taps landed at the center of each form row (`x=187.5`, `y=276.5` and `328.5`), while the switch thumbs were near the trailing edge. Today correctly excluded the undated task. The date-switch helper now targets the trailing thumb and waits for the requested on/off value. Planning, Upcoming, and Waiting scenarios share that helper, so a failed interaction is reported before Save. The helper also dismisses the observed keyboard typing tutorial when its specific message and Continue button are present.

The synchronization failure occurred during the first `app.launch()`, before any task or server interaction. The recording showed partially installed app icons and then a blank launch screen; XCTest timed out acquiring a background assertion. This is a simulator launch-readiness failure, rather than evidence of a failed synchronization operation. The UI wrapper now explicitly boots its owned target and waits for `simctl bootstatus` before starting tests. It continues to leave an already booted target running and shuts down only its owned simulator.

The updated app and XCUITest targets compiled with a generic arm64 simulator destination. A shell probe verified boot/wait/test/shutdown order for an owned simulator and verified that an existing simulator is neither booted nor shut down. No simulator was booted locally. These checks do not establish passing UI execution: the canonical CI gate must execute the corrected scenarios. The successful manual-server UI scenario was skipped in the failed run because no isolated server fixture was configured; it remains unverified at the UI seam.
